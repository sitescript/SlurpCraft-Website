# SlurpCraft-Website

A website made for the Minecraft modpack **SlurpCraft**.
[![Discord](https://img.shields.io/discord/1173279886065029291.svg?color=768AD4&label=Discord&logo=discord&logoColor=white)](https://discord.com/invite/6GQmTZjQQt)
## Building from Source:

To set up the website:

```bash
git clone https://github.com/sitescript/SlurpCraft-Website

cd SlurpCraft-Website
   ```

**Install dependencies**  
   ```bash
npm install
   ```

**Dev Build**  
   ```bash
npm run dev
   ```

> Must have Node.js, NPM & Git installed.
